# 保留任务现场并支持随时接管

用户已确认：任务结束、失败或停止后，继续保留目标 App 当前页面和私有 display，用户从“查看内容 / 接管”进入时可以看到画面并触摸操作。新任务开始或用户显式释放现场时才清理目标与 display。

## 生命周期

- 运行中的任务继续由现有 Agent runtime 托管。
- 任务进入 `DONE`、`PARTIAL`、`STOPPED` 或 `FAILED` 后，停止自动观察，但保留 Shizuku 连接、目标句柄和私有 display。
- 前台服务在现场保留期间继续运行并显示“任务已结束，画面已保留”的通知，避免进程被系统回收后失去预览能力。
- 预览页启动 Surface 镜像并允许用户触摸；关闭预览只停止镜像并恢复目标静音，不释放现场。
- 用户开始新任务或选择“释放画面”时，停止镜像、释放目标/display、关闭连接和前台服务。

## 失败处理与边界

- 截图采集失败不应自动释放正在运行的目标现场；用户仍可尝试通过 Surface 镜像查看并操作。
- 如果镜像或触摸通道启动失败，预览页展示明确错误，现场仍保留供重试。
- 进程被用户强制停止、系统撤销 Shizuku 权限或设备重启后，内存中的私有 display 无法保证恢复；重新进入时应提示现场已不可用并允许重新启动任务。

## 验证

- 对任务正常完成、失败和停止三个终态检查 target/display 仍保留，预览镜像及触摸可用。
- 检查新任务启动和显式释放会完成资源清理。
- 编译 debug APK；在设备上分别验证终态后的再次进入预览、关闭预览再进入、释放后不可预览。
