# 自然语言提交后自动执行

用户已明确批准流程：自然语言任务 → 内部理解目标和约束 → 观察并逐步执行 → 独立核验 → 汇报。普通任务不展示和确认内部计划。

`AutomaticTaskFlow` 在内部准备、契约校验和取消检查后直接调用执行入口。只有缺少必要信息时返回澄清问题；补充答案保留原任务与授权范围，并重新准备后直接继续。`AWAITING_PLAN`、`runPlan` 和计划展示回调从 App 入口移除。

主界面提供开始、暂停/继续、停止、查看画面/接管。界面和通知显示当前进展，不显示内部子目标、节点编号或调试日志。单步模型的可选 progress 只用于展示；独立核验通过后才汇报结果。页面变化仍可改变内部决策。

支付、登录、验证码等交接沿用非抢屏提示。暂停按来源分别记录，关闭预览不撤销用户主动暂停；停止能够唤醒暂停状态，并阻止准备中的模型结果在返回后触发执行。

验证范围：主机测试自动进入执行、澄清前不执行、补充后自动继续、无效内部契约不执行、准备时停止、暂停来源隔离和停止唤醒；编译 debug APK 并覆盖安装。真实第三方任务成功与界面实际效果按实际设备检查记录。
