# 当前页面驱动的任务循环

用户在讨论方案后以“修改”批准本次实现。

## 执行契约

计划确认只确认任务目标、App 范围、预算和最终完成条件，不预先安排点击路径或执行阶段。执行时每轮重新取得当前页面节点与后台截图，模型只返回一个动作、切换 App、请求交接或申请完成。历史仅保留近期动作、实际执行结果和核验反馈。

新循环取代 App 默认的分阶段 SessionRunner 路径。节点动作通过当前观察里的节点编号表达；执行器在新观察中重新定位节点，并允许非点击文字定位到最近的可点击祖先。身份、文字、边界或祖先关系变化时拒绝执行，重新观察。模型不直接拥有设备能力。

## 失败和完成

动作匹配失败或页面没有变化时，将真实结果传回模型；在相同页面禁止重复同一个已失败动作。等待和滚动由当前页面决定。观察对暂时 BUSY / STALE / 非就绪状态在有上限的时间内重试。真正协议错误明确结束并保留错误原因。

Done 是核验请求。独立视觉核验器必须基于新页面证据确认原始目标和所有必需条件，失败则继续循环并携带缺失条件。保留支付、登录等交接以及任务预算、暂停和取消。App 切换只允许在已确认范围内进行。

## 实现边界

节点编号消除对特定文案属性的依赖，截图帮助模型选择实际节点。完全没有可操作无障碍节点的自绘控件仍需要人工介入；本次不引入未经观察约束的裸坐标操作。

## 验证

用主机测试覆盖：无点击文字的父级卡片定位、节点变化拒绝、失败动作反馈及去重、Done 被独立核验否决后继续、允许范围内切换 App、预算和取消。适配器测试覆盖启动中间状态不会被误判为完成。构建 debug APK。真实第三方 App 的成功结果需要另行真机任务证据。
