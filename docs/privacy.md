# AgentNext 内部测试隐私说明（草案）

更新：2026-10-21。项目仍处于纯 GUI Beta 迁移阶段；本文件区分当前数据流与发布前必须实现的保护，不代表完整安全评审已经通过。

## 当前数据流

- 任务目标、计划和阶段数据在 app 运行时处理；任务目标、相关界面文本与 PNG 截图会发送到用户配置的模型服务，用于规划、动作选择、核验与提取。因此不能理解为任务内容从不离开设备。
- API key 与 episodic 事件在 app 私有目录使用 AndroidKeyStore + AES-GCM 加密保存；事件保存任务 ID、时间、类型、摘要与少量键值，不以完整 UI 树或原始帧形式写入该事件文件。
- 设置页支持导入模型配置并保存加密副本。迁移会删除 app 私有目录的旧明文配置；不会删除用户从文件选择器选中的外部源文件。
- 当前事件存储有数量上限，但尚不能按产品目标承诺三十天清理、任务检查点生命周期和完整级联删除。
- 当前 runtime 日志仍可能包含输入文本和部分界面文字；debug smoke 可能写出 `smoke-frame.png`。诊断文件与日志应仅用于受控测试，不应作为已脱敏的产品遥测。
- Debug 版可主动开启电脑只读监看：设备在 app 私有 `cache/demo-monitor/latest.json` 缓存最新 PNG 和状态，停止后保留最后一帧，下一次开启时覆盖。电脑端仅监听 `127.0.0.1`，读取固定缓存文件，帧只在内存中保留，不记录历史；录屏会另行保存，应使用非敏感内容。默认关闭，Release 无开启入口。关闭监看后可在系统应用设置中清理缓存；不要为清理画面而清除应用数据，以免丢失配置。
- 目标 App 音频隔离：Agent 在私有屏操作目标 App 时，capability 服务按目标 UID 建立系统音频策略，把该 App 的播放路由到本地丢弃缓冲，不修改全局音量或系统静音。音频只在内存中短暂缓冲后清零丢弃，**不保存、不上传、不写日志正文**；app 自身不申请麦克风权限，录制发生在 shell uid 的 user service 内。只读监看保持静音，只有用户明确接管（交互预览或主屏接管）才恢复目标 App 声音，交还后重新静音。策略按 UID 生效：同一 App 的其他窗口/后台声音也会一起静音；设备不支持或策略建立失败时阻止任务启动，而不是静默放行。实现与验证边界见[音频隔离验证记录](device-audio-isolation-2026-10-21.md)。
- 当前没有 AgentNext 自有云端账号、分析 SDK、广告 SDK 或社区 registry；模型请求仍受所选服务商的数据处理规则约束。

## 当前用户控制

- “设置与隐私”可导入配置、查看加密配置状态与事件数量、清除 episodic memory。
- 产品入口提供计划确认、停止与接管；风险分类、取消贯通和凭据期间采集隔离仍需完成验收，不能把按钮存在当作保护已完备。用户主动接管时恢复目标 App 声音，只读监看与后台执行保持静音；交还 Agent 后重新静音。
- 卸载会清除 app 私有数据与关联密钥；不会替用户删除外部配置源文件或已经导出的诊断记录。

## 纯 GUI Beta 发布要求

- 截图和页面内容仅按任务所需发送，不默认持久化原始帧、完整 UI 树；输入正文、账号与模型原始响应不进入普通日志。
- 密码、OTP、Passkey、生物识别与支付凭据由用户处理；凭据接管期间暂停采集/模型请求并隐藏预览。
- 任务 WorkingMemory 独立，结束后清理；检查点加密保留最多二十四小时，结构化事件三十天；删除级联覆盖摘要和检查点。
- 承诺动作独立确认，未确认不得执行；任务禁止事项不能通过普通确认解除。
- 不使用直接业务写入接口完成任务；这不意味着 GUI 内容天然不敏感，观察和日志仍须最小化。

上述要求以 [决策记录](decisions.md) 和 [纯 GUI Beta](pure-gui-beta.md) 为准，待对应测试通过后才能升级为已实现承诺。当前无公开分发的正式隐私政策 URL/联系方式；公开发布另行准备。
